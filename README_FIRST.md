# Before the first OpenCode implementation session

1. Clone `https://github.com/shambrain/jumprism`.
2. Confirm that `docs/00_PROJECT_CHARTER.md` exists. If it does not, extract `downloads/Jumprism-Project-Source.tar.xz` into the repository root:
   ```powershell
   tar -xJf .\downloads\Jumprism-Project-Source.tar.xz -C .
   ```
3. Read `README.md`, `AGENTS.md` and `STATUS.md`.
4. Verify the exact Windows build, Unity Hub/editor installation and Unity 6.3 LTS compatibility.
5. Read `docs/03_TECH_STACK_AND_ARCHITECTURE.md`, `docs/07_DEVELOPMENT_ROADMAP.md`, `docs/08_QUALITY_AND_TEST_PLAN.md` and `docs/11_MILESTONE_0_TASK.md`.
6. Implement Milestone 0 only: a manually authored photograph-based platforming vertical slice.

Do not ask OpenCode to implement SAM 2, video tracking, procedural generation, networking or Steam Workshop before Milestone 0 is tested and accepted.
